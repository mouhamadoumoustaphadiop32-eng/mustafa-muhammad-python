# mustafa-muhammad-python

Un petit programme Python qui dessine une rosace de carrés colorés avec le module `turtle`.

## Fonctionnalités

- Dessine 36 carrés qui tournent de 10° chacun pour former une rosace
- Alterne 4 couleurs : cyan, magenta, jaune et orange
- Fond noir, dessin à vitesse maximale

Une fenêtre s'ouvre et le dessin se construit tout seul.

## Personnalisation

- Change les couleurs dans la liste `couleurs`
- Change la taille des carrés en modifiant `carre(100)`
- Change l'angle `t.left(10)` (et le nombre de répétitions) pour obtenir d'autres formes
